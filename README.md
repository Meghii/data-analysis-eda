# Exploratory Data Analysis (EDA) - Starter Project

A starter template for my first end-to-end data analysis project in Python.

## Goal

Take a public dataset, clean it, explore it and communicate findings with clear
charts — the core workflow of a data analyst.

## What's included

- `notebooks/01_eda_starter.ipynb` — a guided notebook with the standard EDA steps
- `requirements.txt` — the Python libraries needed
- `.gitignore` — keeps notebook checkpoints and data files out of git

## How to run

1. Install the libraries:

   ```bash
   pip install -r requirements.txt
   ```

2. Open the notebook:

   ```bash
   jupyter notebook notebooks/01_eda_starter.ipynb
   ```

   Or upload it to Google Colab.

## Suggested datasets

Pick one and download it into a `data/` folder (kept out of git):

- Titanic (Kaggle)
- Netflix Movies and TV Shows (Kaggle)
- IMDb Top movies
- COVID-19 India state-wise data

## Steps I will follow

1. Load the data and inspect it (shape, types, missing values)
2. Clean it (handle nulls, fix types, drop duplicates)
3. Explore it (distributions, group-bys, correlations)
4. Visualise key findings (bar charts, histograms, heatmaps)
5. Write up 3–5 insights in plain English
